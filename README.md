# 🎉 Soirée Jeux

Plateforme de jeux de soirée entre amis, chacun sur son téléphone.

**▶️ Jouer en ligne : https://deux-mensonges-une-verite.onrender.com**

## Fonctionnement
- **QR code** : scanne-le pour rejoindre un salon.
- **Mode salon** : ouvre `/?ecran=CODE` sur une télé ou un ordi : le jeu s'affiche en grand, les téléphones servent de manettes. Rien de secret ne s'affiche sur l'écran.
- **Soirée enchaînée** : l'hôte choisit une durée (20 min à 2 h) ou les jeux à jouer, et 3 à 5 manches par jeu ; les jeux s'enchaînent tout seuls. Points du marathon : 10 pour le 1er de chaque jeu, 1 pour le dernier.
- **Bouille personnalisée** : avant d'entrer, chacun choisit sa bouille (couleur, yeux, bouche, accessoire), modifiable dans le salon.
- **Réponses à l'oral** (réglage de l'hôte) : Note secrète, 2 Mensonges, L'Intrus et Patate chaude se jouent à voix haute.
- Un salon (code à 4 lettres) pour toute la soirée : l'hôte choisit un jeu, on joue, on revient au salon, on enchaîne.
- **Classement de la soirée** : à chaque partie, le 1er gagne autant de points qu'il y a de joueurs, le dernier 1 point.
- Reconnexion automatique si on recharge la page ou perd le réseau.
- **Entraînement avant les jeux manette** (ring, bolides, drapeau) : on essaie les commandes sans enjeu, chacun appuie sur « Je suis prêt », et la 1re manche démarre quand tout le monde l'est (l'hôte peut passer).
- Dans le salon, les jeux sont rangés par familles (bluff, pour rigoler, quiz, équipe, action).

## Jeux
| Jeu | Joueurs |
|---|---|
| 🎭 2 Mensonges, 1 Vérité — devine qui a écrit, puis la vraie anecdote | 3–16 |
| 🗳️ Qui de nous ? — « qui est le plus susceptible de… », vote secret | 3–16 |
| 🕵️ L'Intrus — tout le monde connaît le mot sauf un (ou mode Notes : même note sur 10 sauf un) | 3–12 |
| 📖 Le Dico des menteurs — fausses définitions de vrais mots rares | 3–12 |
| ✍️ La Chute — phrases à trou, vote pour la réponse la plus drôle | 3–16 |
| 💣 Patate chaude — réponds vite avant que la bombe explose (l'hôte peut annuler une réponse) | 2–12 |
| 🏅 Le Classement — devine comment le juge classe la bande | 3–8 |
| 🎨 Dessin en chaîne — dessine, devine, redessine… et regarde le message dériver | 3–10 |
| 🎚️ Note secrète — une note sur 10 à faire deviner : en racontant une histoire, ou en répondant à un interrogatoire | 2–12 |
| 💰 Le Butin — en duo devant un butin : partager ou trahir pour tout prendre | 2–16 |
| 🗡️ Le Complot — des traîtres cachés sabotent vos missions, démasquez-les | 5–10 |
| 🤝 Les Alliances — alliances secrètes, coffres communs… puis fidèle ou poignard | 3–10 |
| 🧼 Le ring savonneux — action en temps réel sur la télé : les téléphones sont des manettes (joystick + A/B) | 2–6 |
| 🏎️ Les Bolides — course de petites voitures sur la télé : drifts qui chargent un turbo, départ canon, aspiration, objets (piment, savon, bouchon, klaxon, mouette), 4 circuits | 2–6 |
| 🚩 La Course au drapeau — on secoue son téléphone pour courir : sprint, feu rouge / feu vert, mât savonné (pas de capteur ? on tape vite à l'écran) | 2–12 |
| 💣 Le Démineur — coopératif contre la montre : bombe qui grossit avec le nombre de joueurs (3 à 8 modules), 7 types de modules et 19 variantes tirées au hasard dont des modules très durs 💀 (câbles multiples, code, interrupteurs binaires, flèches), pièges (fiches tournantes, chrono masqué, court-circuit), règles spéciales à 3 joueurs (chacun ses modules, relais, capitaine, muet, fiches anonymes), manuel découpé entre les joueurs, mode Expert | 2–10 |
| 🔔 Le Buzzer — quiz de rapidité sans propositions : le premier qui buzze répond à voix haute (ou l'écrit), le maître du jeu (l'hôte, qui voit la réponse) valide (+100 / −50 et main aux autres) ; l'hôte peut aussi jouer, estimations (le plus proche gagne), questions « sur nous » (deviner ce qu'un ami a répondu en début de partie), 3 dernières questions à double mise ; difficulté au choix : classique, difficile 🔥 ou de plus en plus dur (par défaut) | 2–12 |
| 🎭 Fais deviner — un paquet de mots qui revient sur 3 manches : parler librement, un seul mot, puis mime. En équipes dès 4 (l'équipe adverse voit le mot et signale la triche) ; à 2 ou 3, chacun pour soi (un joueur fait deviner, les autres devinent). Paquet : mots du jeu, célébrités, ou « nos mots » écrits par les joueurs | 2–16 |
| 🎙️ L'Imitateur — chacun son tour, on choisit un personnage parmi 3 (Gollum, Scooby-Doo, Dark Vador…) et on l'imite devant tout le monde avec sa phrase culte ; les autres notent la prestation sur 10 (moyenne × 10 points, bonus au juge proche de la moyenne) | 2–16 |
| 📊 Le Sondage — « Combien d'entre nous ont déjà… ? » : chacun répond oui/non en secret puis parie sur le total (exact +100, à 1 près +50) | 3–16 |
| 🏷️ L'Étiquette — devinez le prix (ticket de métro, amendes, records d'enchères…) : le plus proche sans dépasser gagne | 2–16 |
| 🎚️ Le Curseur — un donneur voit une cible secrète entre deux extrêmes (Froid ↔ Chaud…) et donne un seul indice ; les autres placent le curseur | 2–12 |
| 🔤 Le Petit Bac express — une lettre, 5 catégories, 75 s ; STOP laisse 10 s aux autres ; réponses contestables, uniques 10 pts / partagées 5 pts | 2–12 |
| 🧳 La Valise — « Dans ma valise, je mets… » : réciter la liste à voix haute et ajouter un objet ; le joueur suivant arbitre (lui seul voit la liste), 2 cœurs | 2–12 |
| 🎶 La Fredonnette — fredonner une chanson sans les paroles (tubes, comptines, musiques de films), le fredonneur désigne qui a trouvé | 2–16 |
| 🤠 Le Duel de cowboys (manette) — téléphone baissé, au signal « FEU ! » le premier qui le lève gagne ; faux départ = duel perdu ; les spectateurs parient | 2–12 |
| 🎪 Le Funambule (manette) — garder une bille au centre en penchant le téléphone malgré le vent qui forcit et le plateau qui rétrécit ; dernier debout gagne (3 manches) | 1–16 |
| 🖼️ L'Image cachée — 10 images à l'écran, tous ont la même sauf un qui n'a rien : démasquez-le | 3–12 |
| ⛩️ Trombi manga — un joueur choisit un perso parmi 158 (ou au hasard), les autres posent des questions oui/non et tapent son nom | 2–10 |

**🗡️ Le Tueur silencieux** (jeu de fond, lancé depuis le salon) : chacun reçoit en secret une cible et une mission (« fais-lui dire “exactement” »…). Il se joue pendant toute la soirée, en même temps que les autres jeux, grâce au bouton 🗡️ en bas du téléphone. Mission réussie → la cible confirme, elle est éliminée et on hérite de sa cible et de sa mission. +2 points de soirée par élimination, +4 au dernier survivant (4 joueurs minimum).

## Lancer en local
```bash
npm install
npm start
```
http://localhost:3000 (ou l'adresse Wi-Fi affichée dans le terminal).

## Structure
```
server.js                 cœur : salons, joueurs, hôte, classement de soirée
games/index.js            registre des jeux
games/<jeu>.js            règles et points d'un jeu (serveur)
public/js/core.js         cœur client : accueil, salon, choix du jeu
public/games/<jeu>.js     écrans d'un jeu
public/css/style.css      style commun
```
Ajouter un jeu : voir [games/README.md](games/README.md).
